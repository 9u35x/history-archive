# تطبيق إدارة دردشة العرب

## الخطوات
1. Android Studio → New Project → package: com.arabchat.admin
2. انسخ محتويات app/src/main من هذا الأرشيف
3. نفس google-services.json لمشروع دردشة العرب
4. عدّل AdminConfig.kt بالإيميلين الحقيقيين
5. أنشئ الحسابين في Firebase Authentication

## حسابان
- إيميل إدارة 1 (رئيسي)
- إيميل إدارة 2 (احتياط)
